# Sonilo 1.1.0：插件升级计划

来源：[在线审阅稿](https://docs.google.com/document/d/1woqbRgMlCemdw46mpP6Wz1uDkVUK9_C4QyPi2cX2y0s/edit)。下表为产品计划；实现状态见 [1.1.0 实现说明](IMPLEMENTATION_1.1.0.md)。

蓝色下划线表示链接位置。视频和修改后的字幕链接由用户提供；试听、下载链接由生成结果返回。

已有网页可点击；【】内为示意，不可点击。余额、资格和结果均为示例。

| 插件里加什么 | 用户说 | 插件回复示例 |
| --- | --- | --- |
| 字幕校对＋配音 | 把这段 1 分钟的产品介绍【视频链接】翻成英文。先给我字幕，产品名改好后再配音。 | 这是【英文字幕文件】。你改好产品名并发回【修改后的字幕链接】，确认后我再按这份字幕配音。 |
| 音乐＋音效 | 给这条 20 秒的海边视频【视频链接】加轻松的音乐和海浪声，直接给我成片。 | 已加好背景音乐和海浪音效。这是【处理后的 20 秒视频】，可以预览或下载。 |
| 配音免费预览 | 把这条 1 分钟的中文视频【视频链接】配成英文，我想先免费试听。 | 你的账户还有 1 次免费预览。这是【前 15 秒的英文配音视频】；剩余 45 秒尚未处理。 |
| 预览后继续做完整版 | 这 15 秒的英文配音不错，帮我把整条 1 分钟视频都做完。 | 我先刷新账户状态，再用刚才的视频和英文设置生成完整版。最终能否生成由服务检查。 |
| 查询余额 | 我还剩多少钱？音乐还能免费生成几次？ | 当前余额 $2；文字生成音乐的免费试用还剩 1 次。 |
| 额度不足提示 | 再帮我生成一段 30 秒的轻快背景音乐。 | 余额不足，这次没有开始生成。当前余额 USD 0。可查看[余额与免费试用](https://platform.sonilo.com/zh/usage-and-entitlements)了解规则。账户更新后，说“继续刚才的音乐”。 |
| 额度更新后接着完成 | 我的账户额度已经更新了，继续刚才那条英文配音视频。 | 当前余额 USD 5。我会先检查原任务，再用刚才的视频和英文设置继续；服务会检查可用额度。 |
| 使用示例 | 我第一次用 Sonilo，想给咖啡店宣传片加音乐，应该怎么说？ | 发来【视频链接】，然后说：“给这条 30 秒的咖啡店宣传片加温暖、轻松的爵士背景音乐。”也可查看「[更多使用示例](https://platform.sonilo.com/mcp)」。 |
| 生成状态 | 刚才那条 1 分钟的英文配音视频做好了吗？ | 这条英文配音视频还在处理中。我会查询原任务的进度，不会重新生成或重复扣费。 |
| 一次生成多个版本 | 给这条 30 秒的咖啡店宣传片【视频链接】配音乐，生成 3 个版本让我选。 | 已生成 3 个版本，每个都是 30 秒：【版本 1 试听】【版本 2 试听】【版本 3 试听】。 |
| 配乐不盖住人声 | 这是我的旅行解说视频【视频链接】。加轻快的背景音乐，但要听清我说话。 | 已加好背景音乐。你说话时音乐会变小，停顿时恢复。这是【处理后的视频】。 |
| 指定位置加音效 | 这段视频【视频链接】第 2–3 秒是关门，第 5–7 秒在下雨，给这两处加音效。 | 已在第 2–3 秒添加关门声，第 5–7 秒添加雨声。这是【处理后的视频】。 |
| 生成音乐并提供分轨 | 生成一段 30 秒的爵士乐。鼓和贝斯也单独给我，方便剪辑。 | 已生成，可以下载：【完整音乐】【鼓音轨】【贝斯音轨】【其他音轨】。 |

「余额与免费试用」页面已上线，包含 View pricing / View billing 按钮；此路径仍待 OpenAI 审核，不能保证通过。余额和“未开始生成”仅在实际返回数据支持时显示。试听、字幕和视频下载链接由每次生成结果返回。

OpenAI 官方参考

[插件商业化规则（Commerce and monetization）](https://developers.openai.com/plugins/plugin-guidelines#commerce-and-monetization)

允许：说明额度不足、链接到权益说明页，以及使用账户已有的付费权益。

不允许：推销数字服务或充值，链接到发起购买、订阅或升级的页面。
